## Fixed during the audit (found by the smoke run, not by the phase tests)

| Defect | Impact | Fix | Evidence |
|---|---|---|---|
| `diff` compared two mirror subtrees, so an unpushed edit produced `files: []` | the command's whole point (see what changed locally) was missing | compare the base subtree with the scanned local tree; per-file patches from `git diff --no-index` over extracted blobs | `TestDiffLocalWorktree`, CLI regression case |
| `push` left `tmp/idx-push-*` behind after every run | `doctor` warned about a leftover on every clean project | `defer os.Remove(indexPath)` | smoke: doctor now `9 ok, 0 warn` |
| `doctor` reported the *record* of the last writer as "is running" | false warning after any completed push; taught users to ignore doctor | take the flock for 200 ms and release it: free → ok with "last writer", held → warn with the real holder | smoke output `[ok] lock: … is free; last writer pid …` |
| dead `validateUserPath` after the multi-docs refactor | lint failure | deleted | `golangci-lint run` 0 issues |

These landed in `887828d` after the phase commits; their phase VERIFICATION files describe the pre-fix state and remain accurate for the criteria they list (no criterion was satisfied only by the buggy behaviour).
